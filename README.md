# Around The U.S. — Galería interactiva de fotografías

## Descripción

**Around The U.S.** es una aplicación web interactiva que permite explorar una galería de fotografías, gestionar tarjetas de lugares y personalizar la información del perfil de usuario.

El proyecto fue desarrollado como parte del **Sprint 6 del programa de Desarrollo Web de TripleTen**, con el objetivo de poner en práctica los fundamentos de JavaScript, la manipulación del DOM y la gestión de eventos.

La estructura inicial de HTML y CSS fue proporcionada como parte del proyecto formativo. Mi trabajo se centró en implementar la interactividad utilizando JavaScript y adaptar el HTML para generar dinámicamente las tarjetas.

## Funcionalidades

- **Edición de perfil:** modificar el nombre y la descripción mediante una ventana emergente.
- **Galería dinámica:** generar tarjetas a partir de un array de objetos y una plantilla HTML.
- **Agregar fotografías:** crear nuevas tarjetas proporcionando un título y la URL de una imagen.
- **Me gusta:** activar o desactivar el estado del botón de cada tarjeta.
- **Eliminar fotografías:** quitar tarjetas de la galería.
- **Visualización ampliada:** abrir imágenes en una ventana emergente con su título.
- **Ventanas emergentes:** abrir y cerrar formularios y vistas de imágenes mediante botones.
- **Valores predeterminados:** utilizar un título y una imagen de respaldo cuando no se proporcionen determinados datos al crear una tarjeta.

## Tecnologías utilizadas

- **HTML5:** estructura semántica y uso de plantillas con `<template>`.
- **CSS3:** estilos y organización de componentes mediante la metodología BEM.
- **JavaScript (ES6+):** manipulación del DOM, eventos, funciones, arrays de objetos y parámetros predeterminados.
- **Git y GitHub:** control de versiones y gestión del repositorio.
- **GitHub Pages:** publicación del proyecto.

## Conceptos de JavaScript aplicados

- Selección y modificación de elementos del DOM.
- Manejo de eventos con `addEventListener()`.
- Creación dinámica de elementos mediante `cloneNode()`.
- Manipulación de clases con `classList`.
- Recorrido de arrays utilizando `forEach()`.
- Uso de parámetros predeterminados.
- Gestión de formularios y eventos `submit`.
- Funciones reutilizables para manejar ventanas emergentes.

## Cómo ejecutar el proyecto

1. Clona el repositorio de GitHub.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Abre `index.html` en un navegador o utiliza Live Server.

No se requiere instalar dependencias adicionales.
